# CLAUDE.md

All project instructions are in [AGENTS.md](AGENTS.md). Read it fully before making changes – it lists which files
must be updated together for every kind of change (games, start page, legal texts, analytics, SEO, domain).

Short version:
- The repo holds sources only: games in `src/`, the hand-written website in `site/`, build tools in `tools/`, tests in
  `tests/`. `dist/` is generated by `python3 tools/build.py`, git-ignored, and published by GitHub Actions.
- Build and test before every commit: `python3 tools/build.py && python3 -m pytest -q tests`.
- Every game and every text in German **and** English; every game has an FSK rating; no outside requests except the
  opt-in Google Analytics; keep `site/privacy.html` (both languages) true; add tests for new features.
- Reply to Matheus in German, kid-friendly.
